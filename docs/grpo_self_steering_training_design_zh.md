# GRPO 联合训练 Self-Steering 方案

状态：方案已确定，训练代码尚未实现。

## 1. 训练目标

在现有 training-free 框架上，通过 GRPO 同时学习根据问题和图像组合能力向量，以及在干预后完成 VQA 推理与作答。路由与作答共享同一个可训练 MLLM，预定义向量库保持冻结。

推理时继续保留“路由 → 合成向量 → 干预作答”流程。这里的内化指模型学会配置和利用能力组合；去除向量库或合并成单轮推理属于后续独立目标。

第一版奖励仅采用格式与最终正确性，不加入干预增益、答案概率、权重稀疏度、长度或人工能力配比奖励。

## 3. 一次 rollout

记问题与图像为 \(x\)，标准答案为 \(a^*\)，模型参数为 \(\theta\)，冻结向量库为 \(V=\{v_1,\ldots,v_6\}\)。

### 3.1 路由段

未编辑模型接收原问题、原图像和六种能力描述，生成权重 JSON 文本：

\[
z\sim\pi_\theta^{\mathrm{route}}(\cdot\mid x).
\]

例如：

```json
{"weights":{"text_logic":0.5,"text_quantitative":0.8,"text_relevance":0.2,"vision_detail":0.4,"vision_spatial":0.7,"vision_grounding":0.3}}
```

路由只配置权重，不解题，标准答案不进入 prompt。

### 3.2 环境转换与向量合成

合法输出通过确定性转换 \(w=T(z)\)：先按 `0.05` 量化，非零时再归一化为 \(\sum_iw_i=1\)。全零保持全零，是合法的无干预动作。

沿用 `weighted_sum`、`global_scale=1.0`：

\[
v(w)=\sum_{i=1}^{6}w_iv_i.
\]

权重表示相对配比，原始分数总和不作为额外剂量。向量加载、解析、量化与合成都是环境操作，不要求可微。

### 3.3 作答段

模型在所选向量干预下，重新读取原问题和图像，生成解题文本与答案：

\[
y\sim\pi_\theta^{\mathrm{solve}}(\cdot\mid x,v(w)).
\]

作答上下文不拼接路由回复，权重通过隐藏状态干预影响作答。沿用目标 decoder block、`phase=both`、`positions=last_token`，请求侧 `coefficient=1.0`。

一次完整 rollout 包含上述两次生成：

\[
\tau=(z,w,y),\qquad
P_\theta(\tau\mid x)=
\pi_\theta^{\mathrm{route}}(z\mid x)
\pi_\theta^{\mathrm{solve}}(y\mid x,v(T(z))).
\]

路由通过生成 token 的策略梯度学习，不对 JSON 到向量的转换求导。

## 4. 奖励设计

### 4.1 格式奖励

\[
F(z)=\mathbf 1[z\text{ 满足路由输出契约}].
\]

合法得 `1`，否则得 `0`。契约要求：

- 输出为单个 JSON 对象，顶层仅包含 `weights`。
- `weights` 恰好包含六个能力 key，无缺失、无额外 key。
- 每个值为 `[0,1]` 内的有限数值，布尔值不作为数值接受。
- 不接受 Markdown 代码块包装或额外说明文本。

通过校验后才量化与归一化；不要求原始权重之和为 1，也不要求原始值已经位于量化网格上。

训练中非法路由直接终止本次 rollout，不进行格式修复，不回退到均匀权重或零向量。现有推理代码允许格式修复，训练时需关闭这一步。

### 4.2 正确性奖励

\[
C(x,y,a^*)=\mathbf 1[\operatorname{verify}(y,a^*)=\mathrm{correct}].
\]

最终答案正确得 `1`，错误或不可解析得 `0`。非法路由没有作答，正确性也记为 `0`。

选择题比较抽取后的选项；开放题使用固定且明确的答案校验规则。现有 `evaluation/answers.py` 提供文本规范化和数值匹配，不覆盖完整数学符号等价，训练与评估需记录实际 verifier。

标准答案仅用于 reward 计算，不进入模型输入。作答格式不额外计分，无法解析答案时由正确性奖励记为 `0`。

### 4.3 分段总奖励

\[
\boxed{R^{\mathrm{route}}=F+C},\qquad
\boxed{R^{\mathrm{solve}}=C}.
\]

两项均采用固定单位分值，不额外搜索奖励混合系数；该计分约定仍需如实报告。

| 轨迹结果 | 格式奖励 | 正确性奖励 | 路由总奖励 | 作答奖励 |
|---|---:|---:|---:|---:|
| 路由非法，无作答 | 0 | 0 | 0 | 0，作答 mask 为空 |
| 路由合法，答案错误或不可解析 | 1 | 0 | 1 | 0 |
| 路由合法，答案正确 | 1 | 1 | 2 | 1 |

全零与非零权重使用相同奖励规则，不强制模型必须施加干预。

## 5. 分组采样与优势计算

每个问题在同一采样策略 \(\theta_{\mathrm{old}}\) 下独立生成 \(G=8\) 条完整轨迹。训练需启用采样，不直接照搬现有推理流程中作答温度为 `0` 的设置。

先为每条轨迹计算两段奖励，再分别计算组内优势：

\[
r_j^{\mathrm{route}}=F_j+C_j,\qquad
r_j^{\mathrm{solve}}=C_j,
\]

\[
A_j^s=\frac{r_j^s-\overline r^s}
{\operatorname{std}(r_1^s,\ldots,r_G^s)+\epsilon},
\qquad s\in\{\mathrm{route},\mathrm{solve}\}.
\]

固定标准差计算约定，零方差组的奖励优势置零；\(\epsilon\) 仅作数值稳定处理。

本方案两段奖励统计均保留同一组八条轨迹。非法路由的作答奖励为 `0`，其作答段无生成 token，不参与作答 loss；整组均非法时没有作答 loss。

路由优势作用于路由生成 token，作答优势作用于作答生成 token。输入 prompt、图像和环境操作不作为生成动作计入 policy loss。两段分别应用裁剪策略目标，共同更新同一模型参数。

两段的有效 token 归约方式需明确固定，避免长回答仅因 token 数量更多而无意淹没短路由段。这需要支持两次模型调用与分段优势的训练器。

### 格式奖励抵消与零方差组

八条路由均合法时，格式奖励为共同常数：

\[
r_j^{\mathrm{route}}-\overline r^{\mathrm{route}}
=C_j-\overline C.
\]

此时路由完全依靠最终正确性学习。若八条还全部答对或全部答错，两段奖励优势均为零。该现象本身不能证明模型坍塌。

本方案接受正确性奖励的稀疏性，不额外加入答案概率或干预增益来制造组内差异。

## 6. 实现约束

### 6.1 两段都必须进入 loss

保存路由与作答各自的 token、旧策略 logprob、有效 token mask、奖励与优势。只训练回答而丢弃路由 logprob，不能直接优化路由策略。

### 6.2 重算 logprob 时复现干预

路由段使用无干预模型概率；作答段使用该轨迹实际采用的向量、层号、阶段与位置。新旧策略均以已经采样的同一组权重计算作答概率，不重新采样路由。

Teacher-forcing 重放需复现 prefill 最后一个 prompt token 以及后续作答预测位置上的干预，不能只对整个训练序列最后一个 token 加向量。不得用未干预的作答 logprob 替代。

如采用 KL 正则，参考策略也使用对应的相同条件。KL、策略裁剪等属于优化设置，与任务奖励分别记录。

### 6.3 训练不使用 baseline 无答案门控

每个训练问题都执行所定义的路由与干预作答，不沿用 `--baseline-no-answer-only` 跳过已有可解析 baseline 答案的问题。

无干预 baseline 作为独立评估对照，不参与当前奖励，也无需为每条训练 rollout 额外生成一次。

### 6.4 固定向量与模型更新

同组采样策略保持一致，正确同步生成端和训练端参数，记录向量内容指纹。

参数更新后，冻结向量在隐藏空间中的作用可能变化。需定期检查实际 steering 效果及验证集表现；文件冻结不保证语义作用恒定。全参数或 LoRA 的具体更新范围在实现阶段确定。

### 6.5 基础设施错误单独处理

非法 JSON、权重越界和结束后答案不可解析按模型输出计分。网络中断、服务异常等不伪装成模型零奖励样本，按固定恢复策略重新收集可用轨迹组。

## 7. 日志与验证

逐轨迹记录原始路由输出、实际权重、向量标识、合法性、回答、抽取答案、正确性、两段奖励和优势。

训练监测包括格式合法率、最终正确率、答案可解析率、全零权重比例、权重分布与组合差异、两段奖励标准差和零方差组比例、分段 policy loss、采用时的 KL，以及固定验证集表现。

对训练后的同一模型，在相同问题、生成预算和注入设置下比较：

| 推理条件 | 验证目的 |
|---|---|
| 学习得到的路由权重 | 完整方法表现 |
| 六能力均匀权重 | 相对固定组合的价值 |
| 打乱问题与权重对应关系 | 是否具有问题相关性 |
| 零向量 | 相对训练后无干预模型的收益 |

另保留训练前模型和原 training-free 流程作为整体对照。训练数据与验证/测试数据分离，不使用测试答案更新参数。

这些对照用于验证组合是否有效，不构成额外奖励。方案不预先保证模型学到有用组合，相关结论由实验支持。

## 8. 已确定与待实现事项

已确定：冻结六向量库；同一模型执行路由与解题；每次 rollout 包含两段生成；每题八条 rollout；路由 `format + accuracy`，作答 `accuracy`；固定单位分值；非法路由终止；分段计算优势并共同训练。
